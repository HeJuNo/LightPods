# LightPods (BlazePodPOC)

## Overview
Native iOS app to control BlazePod reaction training pods over BLE. No backend. Bundle ID: `com.hejuno.lightpods`.

## Architecture
- **BLEManager** (`@Observable`, CBCentralManager/CBPeripheralDelegate): handles scanning, connection, auth handshake, color commands, tap notifications
- **PodDevice** (`@Observable`): model for a single pod with connection state, BLE characteristics, selected color
- **DrillManager** (`@Observable`): random drill logic — picks random authenticated pod, lights it, records reaction times
- **PodColor** enum: 7 preset colors with GBR byte conversion for the BlazePod protocol

## Visual Style
- Dark mode preferred (`.preferredColorScheme(.dark)`)
- Cards with `Color(.systemGray6)` backgrounds, rounded corners
- SF Symbols throughout

## Tabs
1. **Scan** — BLE discovery, add devices
2. **Pods** — Connected pod cards with color picker, light up, disconnect
3. **Drill** — Random reaction drill with stats

## BLE Protocol
- Auth: "sea" + 4-byte XOR/offset computation from manufacturer data
- Color: [G, B, R, 0x01] to color characteristic
- Tap: 8-byte notification, byte[0]=state, bytes[1-4]=LE uint32 ms

## Capabilities
- `bluetooth` configured

## Build System
- GitHub Actions workflow at `.github/workflows/build.yml` (self-hosted runner)
- Fastlane: `build` and `test` lanes
- Manufacturer data key: use `"kCBAdvDataManufacturerData"` (the string constant `CBAdvertisementDataManufacturerSpecificDataKey` is not in scope in newer SDKs)
